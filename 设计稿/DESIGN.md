# 客服工作台 · 静态设计稿

## 设计方向

按用户指定的 https://www.agents-anywhere.com/ 进行视觉参考，保留深色要求。实际检查了该站的页面与计算样式：正文采用 SF Pro Text / 系统字体，标题采用 SF Pro Display / 系统字体，中文由苹方等本机字体回退。这里沿用相同字体栈，采用 24px 页面标题、17px 客户名、15px 对话正文、12–14px 辅助信息；手机对话正文为 16px。没有分发 Apple 商业字体文件，跨操作系统的字形会有所差异。

使用 ui-ux-pro-max 检索 Minimalism & Swiss Style、文字层级及 html-tailwind 响应式布局规则。两次 design-system 结果中的版式部分都偏营销页面，未采纳；采用通用工作台布局原则，并按用户参考增加圆角与胶囊按钮，优先保留信息密度和可读性。

## 布局与交互

- 左侧为会话收件箱，中间为当前对话和回复区，右侧为问题、订单、客户与处理记录。
- 四项全局统计保持全局口径；五项当前结果统计随搜索和筛选变化。原有九项指标均保留，底部短标签提供完整名称的提示与无障碍标签。
- 待接入、人工、AI、已解决状态有独立的标签与操作；接入后可回复，解决后可以重新接入。
- 搜索、状态筛选、热度/时间排序、全局指标筛选、空结果、回复校验、快捷回复、备注及刷新反馈均在本地模拟。
- 小屏先展示队列，选中会话后进入对话；详情面板按需打开，支持 Escape 返回。不会把中文姓名挤成竖排。
- 所有客户、订单与消息均为虚构示例，刷新页面恢复初始数据。附件仅展示样式，不上传文件。

## 组件与迁移边界

Tailwind Browser v4 负责布局、间距与响应式；Basecoat CSS 与运行时负责按钮、表单、标签页和 Toast；Lucide 统一图标；Motion 仅用于发送新消息的轻量过渡，遵守减少动态效果偏好。页面不含统计图，因此不加载 ECharts。所有依赖已本地打包，版本、官方源 URL 与 SHA-256 见 `vendor/manifest.json`，许可证见 `vendor/licenses/`。

`theme.css` 是唯一语义颜色源；`demo-data.js` 集中保存演示数据；`app.js` 中的 `state` 保存演示业务状态，渲染函数与业务动作分开。后续 React + shadcn 实现可以复用 token、数据结构、图标名称和交互规则，需要重新实现渲染及状态绑定。正式应用应采用仓库预编译样式，不使用浏览器 Tailwind。

## 打开

直接打开 `index.html`，或在当前目录启动静态服务。当前预览为 http://127.0.0.1:18766/ 。无需安装或构建前端依赖。

## 浏览器验收

已在真实 Chromium 页面操作搜索空结果、状态筛选、接入、空回复校验、发送、解决、标签页切换及手机详情开关。手机详情支持 Escape 返回且同步 aria-expanded；提示浮层不拦截回复按钮。减少动态效果模式下发送成功，按钮计算过渡时间为 0s。

检查 375×812、768×1024、1024×900、1440×1000、1920×1080 和 812×375 布局，未发现页面横向溢出。按钮、选中队列、选中筛选、警告、成功、辅助文字和禁用按钮覆盖正常、悬停与按下等共 21 组文字对比度样本，最低 6.49:1；原始数据及结果见 previews/contrast-*.json。浏览器控制台未发现错误。最终桌面图见 previews/desktop.png。
