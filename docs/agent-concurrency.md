# 多用户与多 Agent 并发

不同用户、不同会话可以同时执行 Agent；同一个 Agent 的多个会话也可以并发。
并发按正在运行的一轮聊天计算，与在线用户数、Agent 配置数量无直接对应关系。

## 执行与隔离

聊天入口先核对请求用户与会话归属，并确定本轮 Agent：已有会话沿用 `conversation.agent_id`，
未绑定的会话使用请求中的 `agent_id`，两者均未指定时使用默认 Agent 并保存绑定。
已绑定的会话不能改用其他 Agent；切换时需新建会话。不存在或禁用的 Agent 不会自动改用默认配置。
系统仍沿用匿名用户标识，用户 ID 校验不替代登录认证。

普通商品、FAQ、知识库和自定义 Agent 使用已有 Agent SDK 执行。
`business_domain=complaint` 或 `role_tag` 为 `front_desk/planner/executor/reviewer` 的 Agent
进入客诉流程，Executor 使用所选 Agent 的提示词和知识源配置。

客诉主链路按以下阶段提交：

1. 校验会话并保存用户消息，提交事务。
2. 完成 ticket 归并、triage 和 plan 任务建立，提交后调用 Planner 模型。
3. 保存规划结果和 executor 任务，提交后调用 Executor 模型及工具。
4. 保存执行结果、审查与会话状态，提交事务。
5. 输出回复和事件，保存 assistant 消息。

模型及工具的网络等待不会持有上述写事务。已提交的任务在客户端取消或运行异常时记录失败，
流关闭会停止后台 Agent，再释放本轮运行名额。已保存的用户消息保留，未完成的回复不作为成功回复落库。
阶段提交意味着运行不再是一个整体事务；不能通过回滚撤销已完成的阶段。

编译后的 Agent 图按 Agent ID 和输出模式缓存。同一 Agent 冷启动只构建一次，不同 Agent 可独立构建。
会话历史继续按 `conversation_id` 保存在 checkpoint；运行上下文、工具串行锁和 TODO 去重状态按本轮创建。
同一会话在上一轮完成、停止和清理前再次发送，返回 `409`，并且不会插入第二条用户消息。

## 并发配置与响应

```dotenv
CHAT_MAX_CONCURRENT_RUNS=16
```

此值是单个后端进程允许同时运行的聊天数量，覆盖准备、模型调用、事件流和落库阶段。
默认值是资源保护设置，实际容量还取决于模型接口配额、工具耗时、上下文长度和服务器资源。
HTTP 连接或浏览器在线人数不等于 Agent 运行数量。

| 情况 | 响应 | 是否保存新用户消息 |
| --- | --- | --- |
| 同一会话已有运行 | `409` | 否 |
| 请求 Agent 与已有会话绑定不同 | `409` | 否 |
| 用户与会话不匹配，或会话/Agent 不存在、Agent 禁用 | `404` | 否 |
| 进程达到并发配置 | `503`，`Retry-After: 5` | 否 |
| 开始输出 SSE 后发生执行失败 | `error` 事件 | 已保存的用户消息保留 |

超过并发上限时立即拒绝，不建立无界等待队列。客户端应保留输入并提示用户重试。
同一会话的重复请求应等待当前回复完成或停止；切换 Agent 应建立独立会话。

## 部署范围

当前准入控制和 WebSocket 连接管理都属于进程内状态，部署继续使用单个 Uvicorn worker。
一个异步 worker 可以让多个 Agent 网络请求同时等待和执行，无需为每个用户创建进程。
SQLite 保留短事务，可用于单实例并发；生产扩容可切换现有 PostgreSQL Provider。
切换数据库前需要迁移业务数据和 checkpoint，不能仅更改环境变量后忽略原数据。

多 worker 或多实例需要另外接入共享运行租约和全局配额，并把 WebSocket 通知通过共享消息通道转发，
同时协调定时任务和文件记忆存储。单纯设置 `--workers` 无法使这些进程内状态一致。

## 验证

在 `backend/` 执行：

```sh
uv run python scripts/verify_chat_concurrency.py
```

脚本使用自动清理的一次性 SQLite 数据库，模型替身通过屏障证明不同运行的 Planner、Executor
可以同时进入，且进入时没有数据库事务；同时验证普通 Agent 路径、身份与消息隔离、
重复提交、超额拒绝、冷启动去重、工具锁、TODO 广播和取消回收。脚本不调用外部模型。
真实容量应使用目标服务器、模型配额和业务上下文进行阶梯压测后确定。
