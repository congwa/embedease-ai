# 深色客服工作台

开发分支：`codex/support-dark-workspace`。以 `设计稿/index.html` 为视觉依据，使用现有 Next.js、React、shadcn、Tailwind 和 Lucide 实现，没有引入浏览器 CDN 或新增依赖。

## 页面与数据

`/support/layout.tsx` 提供路由元信息与样式；`workspace.tsx` 持续承载队列、全局统计、搜索筛选及后台订阅。`/support/[conversationId]` 承载当前会话的真实消息、人工接入、回复、图片、FAQ、消息编辑撤回和工单操作。当前会话由详情页独立订阅，队列不再对同一会话重复建立客服连接。

全局四项指标来自统计接口；底部五项指标来自当前加载、搜索与筛选后的会话。高热筛选与后端采用相同的 `> 60` 口径，未读指标筛选待接入和人工服务中的会话。搜索范围为已加载会话的客户 ID、会话 ID、标题、消息预览和问题标签；保留接口原有的默认加载数量。

手机先显示队列，进入会话后保留返回入口；问题概览和处理记录通过 Radix Sheet 打开，Escape 关闭并返回触发按钮。桌面三栏独立滚动。客服主题 token 仅作用于本路由及其显式标记的弹层。

没有将设计稿的虚构客户、订单或快捷回复写入正式页面。订单等业务字段仅通过已有工单槽位/历史展示；未添加不存在的业务接口。

## 验收记录

- ESLint（客服路由与本次涉及的共享编辑器、WebSocket 文件）、TypeScript 无输出通过。
- `pnpm build` 和 `pnpm build:embed` 通过。
- 本地后端与真实浏览器完成：搜索空状态、人工接入/结束、按钮发送、Enter 发送、工单解决/重新打开、处理记录标签、手机返回队列、详情抽屉及 Escape 焦点返回。
- 使用独立的本地 SQLite 验收会话操作，HTTP 重新读取确认发送的回复已持久化。生产数据与线上服务未参与验收。
- 375×812、768×1024、1024×900、1440×1000、1920×1080、812×375 未发现页面横向溢出。手机回复正文与编辑器为 16px，编辑器焦点轮廓为 2px。
- 21 组正常/悬停/按下的文字和图标颜色样本，最低对比度为 4.62:1。减少动态效果模式下过渡为 0s。强制状态与尺寸模拟均已清除。
- 独立浏览器页复验接入、发送后无控制台 error。

截图与颜色采样位于 `设计稿/previews/implemented-desktop.png`、`implemented-mobile.png`、`implementation-contrast-*.json`。图片附件、消息编辑撤回和 FAQ 保留原有接口与控制流，本轮未逐项执行这些写入操作。
